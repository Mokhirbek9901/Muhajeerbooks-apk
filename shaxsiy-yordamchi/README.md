# Shaxsiy yordamchi

Kitoblarim va shaxsiy hisob-kitobim uchun PWA.

Ilovaning ishlaydigan manzili: https://bek-shaxsiy-yordamchi.ds5xshg8tk.chatgpt.site/

## Telefonga ilova qilib qo‘shish

1. Havolani iPhone’da Safari orqali oching.
2. **Ulashish → Add to Home Screen** ni bosing.
3. **Open as Web App** yoqilganini tekshiring va **Add** ni bosing.
4. Ekrandagi **Yordamchi** belgisini bossangiz, ilova alohida oynada ochiladi.
